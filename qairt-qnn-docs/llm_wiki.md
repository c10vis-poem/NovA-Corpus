# qairt-qnn-docs — LLM Wiki

## What this is

Reference documentation for Qualcomm's AI Runtime (QAIRT) and QNN SDK. Covers:
- Hexagon HTP v79 programming model (SM8750)
- ONNX → QNN context binary compilation pipeline
- `libqnn_htp.so` and related library references
- `qnn-net-run` usage, performance profiling flags

## Key device target

Razr Ultra (SM8750) — 16GB RAM, ~45 TOPS, Hexagon HTP v79. All compilation parameters are keyed to this SoC.
