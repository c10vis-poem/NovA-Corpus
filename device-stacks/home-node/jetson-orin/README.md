# jetson-orin

Jetson Orin Nano Super — main compute hub, runs headless.

## Specs

8GB RAM · 512GB DDR4 SSD (added) · ~67 TOPS

## Access

- Desk: display via Rubik Pi 3 (wired)
- Couch: AVNC from Galaxy Tab S9 FE+ (Wi-Fi only) over Tailscale
