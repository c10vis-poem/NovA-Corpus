# install-guides — LLM Wiki

## What this is

Installation and setup guides for every tool in the stack. Source docs (PDFs, txts) each get a clean `.md` sibling in template format. Raw file = artifact anchor; `.md` = working doc.

## Scope

GitHub · HuggingFace · Qualcomm AI Stack · Termux environment · Tailscale · Jetson Orin Nano Super · Rubik Pi 3 · any SDK or CLI in the system
