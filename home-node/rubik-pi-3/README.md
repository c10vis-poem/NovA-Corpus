# rubik-pi-3

Rubik Pi 3 — DragonWing chipset. Visual OS, dual monitor, keyboard hookup.
Wired directly to Jetson Orin Nano Super via high-speed data cable.

## Specs

DragonWing chipset · 8GB RAM · ~128GB built-in SSD · ~14 TOPS

## Role

- Provides visual output for the headless Jetson (desk display)
- Dual monitor setup
- Keyboard and peripheral hookup
